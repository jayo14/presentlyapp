Implementation of Multi-Sample Polygon Geofencing:

1. Backend:
   - Added 'accuracy' field to Attendance model.
   - Created 'AttendanceAttemptLog' model for zero-trust auditing.
   - Implemented pure Python ray-casting point-in-polygon algorithm in 'geolocation_utils.py'.
   - Refactored check-in logic into 'attendance_logic.py' to validate 4 samples, check accuracy (<= 30m), and use atomic transactions.
   - Verified with comprehensive unit tests (CheckInTests).

2. Web Frontend:
   - Migrated VenueMap from Leaflet to @react-google-maps/api.
   - Implemented polygon drawing with GeoJSON coordinate extraction (lng, lat).

3. Mobile App:
   - Implemented 20-second sampling logic (4 samples, 5s interval).
   - Added high-accuracy requirement and client-side accuracy rejection.
   - Implemented sampling progress UI.
